Practical engineering takeaways from system bugs that cost hours to diagnose.

The Beeping BLDC ESC Mystery

Hardware / PWM Initialization

Powered up the BLDC and it just... beeped, like a time bomb. I spent hours assuming I'd broken something. Turns out the ESC was simply waiting for a valid PWM signal before arming.

WSL2 UDP Firewall Blocking ROS2

Networking / DDS Discovery

ROS2 nodes running in WSL refused to find Windows. After checking DDS settings, networking and environment variables... it was Windows Firewall blocking UDP.

New-NetFirewallRule -DisplayName "Allow ROS2 WSL" -Direction Inbound -Action Allow -Protocol UDP

Gazebo Sensor Plugin Calibration

Simulation vs Reality

I expected sensor simulation to be complicated. Instead, attaching a plugin and placing it correctly was enough to give my robot cameras, LiDARs, IMUs and GPS.

Inverted Pendulum PID Tuning

Control Systems

Every initial PID tuning attempt ended in violent oscillations or immediate crashes. Balancing derivative gain Kd to dampen angular acceleration proved far more critical than aggressive proportional Kp response.
